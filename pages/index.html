A better Hacker News

Dark mode, faster loading, favicons, archive links, user hover cards, comment tools and more. 35 KB, no framework, works on the real site.

Download for Firefox Download for Chrome Feature list

What it is

  • Dark, light and system themes in HN's own colors, with the original density kept intact
  • New comments highlighted when you reopen a story, thread tools, ignore users, domain and keyword blocklists
  • Copy · archive.is · Wayback links on every story, user hover cards, live scores
  • Keyboard nav: j/k move · o comments · l article · v vote · / search

Install (Firefox)

  • Click the download button above.
  • __INSTALL_NOTE__
  • Prefer tinkering? Open about:debugging#/runtime/this-firefox → Load Temporary Add-on… → pick manifest.json in the unzipped build.

Install (Chrome)

  • Download the Chrome zip, unzip it, open chrome://extensions, enable Developer mode and click Load unpacked.
