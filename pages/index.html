A tasteful modern layer over Hacker News

Faithful to the original, just modern. ~35 KB, no framework, nothing polled.

Download for Firefox Download for Chrome Feature list

What it is

  • Restyles and augments the real news.ycombinator.com — login, voting, commenting all native
  • Light / dark / system theming, black-on-orange, square corners, original density
  • New-comment highlighting, thread jumping, collapse tools, ignore users, domain & keyword blocklists
  • Copy · archive.is · Wayback links on every story; user hover cards; live scores
  • Keyboard nav: j/k move · o comments · l article · v vote · / search

Install (Firefox)

  • Download the Firefox zip above and unzip it.
  • Open about:debugging#/runtime/this-firefox → Load Temporary Add-on… → pick manifest.json inside.
Firefox permanently installs only AMO-signed extensions. A persistent one-click install needs an unlisted self-distribution signature — the signed build will appear here when signing is wired up. Until then, temporary loading works for the whole session.
